# 元控件与图文混排修订

日期：2026-10-02。设计 r3，安装预览 r8。实施前基线：当前会话项目 R48，安装 UI r2；本轮最终内容 R73。用户指出标题节点缺乏解释、分析视角和控件；要求图文融合及 WPS 文本框式插入编辑。设计与实际验收统一记录于本文。

## 设计结论

内容、呈现和交互各有自己的身份。对象持有摘要、可排序的分析分节和来源；图上表示选择紧凑、摘要卡片或全文。文本框与图片、对象和连线平级参与自由排版。阅读页按明确顺序排出同一批内容，提供正文、章节目录、原图及进入子图的控件。阅读页是工作区视图，不是另行维护的 HTML 报告。

紧凑图仍适合看关系，完整解释用阅读页或展开的内容卡片。分析视角描述同一对象，子图表达独立结构；两者可以同时存在。默认以摘要辨认模块，直接点视角查看说明，并可从卡片进入相关子图。

## 元控件

| 控件 | 正常操作 | 数据与反馈目标 |
| --- | --- | --- |
| 模块 | 标题、摘要、视角页签、来源与子图入口；编辑可排序分节 | 共享 Entity，按 Representation 定位 |
| 文本框 | 插入即编辑；双击原位编辑；字体、大小、颜色、粗斜下划线、段落、对齐及列表 | FreeElement 稳定身份 |
| 排版手柄 | 拖动块标题栏；右下角缩放；可编辑宽高、填充与边框 | 仅当前表示/自由元素几何 |
| 阅读页 | 原生滚动、章节目录、全文/指定视角切换、图片、子图入口 | 同一 Graph 的显式 Reading Order |
| 顺序面板 | 上移、下移及块定位 | typed block refs，区分表示和自由元素 |
| 批注 | 选中内容后沿用直接独立批注；保存观察版本 | 现有 TargetRef 与反馈批次 |

## 持久化与一致性

- `Entity.metadata.semanticContent` 保存版本化摘要、稳定分节 ID、正文 HTML 和来源标签；`Representation.style.contentView` 保存显示密度。
- `FreeElement.element.customData.richTextBox` 保存版本化文本框内容和排版属性。原生矩形是几何承载，派生文字保证缩略图/导出包含内容；派生文字不成为第二份可写记录。
- `Graph.metadata.contentWorkspace` 保存阅读顺序及默认视图。未知扩展数据保留。当前 r1 服务即可事务保存这些既有扩展路径，无需重启当前 MCP。
- HTML 经允许列表处理后才显示/保存，移除脚本、事件、危险 URL 和非文本格式样式。粘贴经过相同处理；不加载远程字体或编辑器服务。
- 编辑开始冻结基线及对象；切图、实时更新不重置草稿。同一字段冲突保留草稿，明确显示冲突；待确认队列不当作服务已保存。
- 图上操作不重排其他块。阅读顺序不改变自由排版的位置。用户在 R45–48 固定的 `fc-main-1`、`fc-main-source` 几何保持。

## SDK 边界与本轮验收

Excalidraw 负责原生图形、关系线、相机及选择；DOM 内容层负责分节与富文本编辑，通过公开相机和选择 API 对齐。不会把内容塞进原生标题编辑器。文本框提供常用文字及段落格式，不承诺 Word/WPS 的分页、浮动环绕、样式集或完整印刷排版。

必须实测：插入即编辑 → 格式修改 → 保存 → 拖动/缩放 → 刷新仍在；模块摘要与视角切换/编辑；阅读顺序改变但画布几何不变；内容更新无额外原生写入；派生文字可预览/导出；版本冲突不覆盖他人；通过当前 MCP 丰富论文并保留用户排版。

论文讲解顺序：研究问题 → 分类与两类记忆 → 预测链 → 结果揭晓后的诊断/聚合/修订 → 解释性例子 → 指标/对照与消融 → 来源和局限。作者结果、讲解案例和我们的分析分别标示，不声称复现实验。

## 部署与剩余边界

`current` 指向 `versions/0.1.0-local-20261002-r8`。已运行的 stdio 进程继续使用 r1 服务，页面加载 r8；下次启动使用完整 r8。程序和项目数据分离，旧版本、原 4317 服务/数据和源码 dist 保留。元控件没有新增第三方编辑器或远程字体依赖。

富文本内容和格式完整保存在原生项目包内；当前 SVG/PNG/图缩略投影用派生纯文本，不能宣称富文本样式、字号跨度及表格视觉保真。完整 Word/WPS 分页、文字环绕、打印与导出 DOCX 未实现；本轮手柄以无旋转排版为验收样例，旋转排版另验。原生 Windows、Claude 专用宿主、Codex 原生标注以及富文本场景的完整可见性能预算仍待验收。阅读页使用原生滚动，本轮未把返回后的正文滚动位置恢复列为通过项；原 SDK 图相机仍沿既有机制保存。

论文中的指标为作者报告值，本机未复现实验；讲解用选举例子和 EvoFore 借鉴方向分别标明案例与待检验假设。
