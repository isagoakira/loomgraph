## 当前范围与限制

常驻的是可收起入口、对话窗口与会话，模型仅在提交请求后按需运行。可使用六类受约束控制：跳图、返回、定位、高亮、适配和缩放；没有任意浏览器脚本执行、新建图或业务执行权限。

页面助手每轮读取当前图的有界语义摘要和图目录，并将当前选区作为只读资料。它没有接收截图，不保证读入全部节点细节或屏幕上完整视觉状态。模型本轮只使用最近 8 条消息；服务按上限保留会话与消息，不接入宿主的完整聊天历史。

草稿保留指收起以及当前页面中的作用域切换。尚未实现刷新或关闭页面后的草稿持久化；不能把会话历史恢复表述为草稿也已恢复。

Windows、真实 API 服务及 Claude 模型的本轮页面控制尚未实机验收。选区的预览、应用和撤销沿用已有实现，本轮重点验证冻结范围和跨图保留，没有重复全部真实写入生命周期。旧 r30 主项目与活动 MCP 进程保留，不能将新安装版本等同于当前宿主连接已经切换。本轮没有远端仓库提交或发布。
