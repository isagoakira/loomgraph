# 局部概念图解与分支结构修订

用户已认可文风和知识粒度，本轮保持当前概念身份、定义和必要回顾，修正无图例和线性陈列。验收对象是 ForecastCompass 的现有知识结构样例及真实 MCP 上下文。

1. 八步各绘制一张有内部含义的 SVG。概率用分配条、分类用目录分支、双记忆用成对手册、校准用群体对照、更新用时间分隔的两条轨迹、研究用指标与独立实验臂。图解明确区分讲解示意与论文报告。
2. 卡片围绕当前问题的中心概念分支展开。分支组织与知识边、讲解顺序分别记录，保留规范交叉关系和回路，不根据放置方向新增语义。
3. 图形部件绑定知识中心身份。点击或键盘激活时在图边就地说明定义与用途，并联动对应卡片；悬停不激活。继续探索沿关系进入邻域，返回恢复图和阅读位置。
4. SVG 使用独立稳定 figure/part 身份，可用于局部修改。Agent 的视觉上下文记录图的表达目标、图形部件、知识身份、来源与当前分支组织，避免只有图片没有可读语义。
5. 验收覆盖真实浏览器桌面及窄窗口、图形/部件可操作性、几何可读性、图例点击、卡内展开、邻域返回、论文原表保留及实际 MCP 上下文。保存变更与证据。

窄窗口提供可横向查看的图例，保持字号，不以缩到不可读来换取整图适屏；卡片关系按嵌套分支展示。图例不代表论文实验复现；真人理解效果需另验。通用原生渲染器和安装更新按实际完成情况记录。
