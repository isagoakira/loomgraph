# 项目状态与图上表示分别持久化，通过变更记录统一关联

一个任务需要同时出现在结构图、流程图和总览中，用户还需要自由绘图、局部批注及跨版本恢复。采用独立的业务对象和图上表示身份，将业务记录、各图视觉记录、自由图形、批注与变更历史保存在项目存储中；Excalidraw 场景是这些记录面向编辑器的投影，业务身份不依赖文字或位置。

仅保存 `.excalidraw` 场景会把任务状态、多视图一致性与绘图元素耦合，也难以表达批注观察版本和真实运行来源。所选方案增加适配和映射成本，但能让局部布局、讨论定位、项目包迁移及历史恢复共用稳定身份；自由图形及用户样式也必须持久化，不能仅从业务对象重建后丢弃。

项目修改与变更记录在一个本地存储事务中提交。历史恢复形成新变更；恢复画布内容不撤销外部执行。宿主会话连接及当前服务状态属于本机运行时，项目迁移后重新关联。
