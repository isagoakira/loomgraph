# 关系展示第二阶段：线跳、共享主干与边段编辑

## 交互与保存契约

1. 无关的正交线相交时，次要路径留小间隙；共同端点、共享线段和真实汇合点不产生断口。保持原始命中路径，避免难以点选。箭头由单独的最终尾段绘制，不在每个断口末端重复出现。
2. 兼容的同源或同目标关系可以共享主干。只有方向、样式一致且通道和标签安全才汇合；原有条件、关系 ID 和业务含义独立保留。点击主干打开成员列表，点击成员追踪其端点。选中关系后可点“共享主干”，点击主干可点“独立显示”；设置是有版本保护的一次事务。
3. 选中关系 → “编辑连线” → 拖动圆点对应的边段，或方向键微调 → “保存连线”。第一段、末段移动采用短连接保持端点，内部线段只做垂直于自身的移动。预览不写内容历史，取消或 Esc 回到原路径；保存中的 Esc 不会假装撤销已提交请求。
4. 保存手工线路会记录路径和端点锚点。移动节点时端口跟随节点，内部中间点保留；手工线路退出共享主干。“恢复自动”清理手工路径与锚点，未知 metadata 命名空间保持。内容撤销与重载使用现有版本历史。
5. 无效、穿过卡片/自由内容、非正交、过量或非有限坐标无法保存。版本变化须重新编辑；排队、失败、冲突与已保存分别显示。切图或切工具清理预览，异步回执不污染另一图的说明。

## 实现责任

- `relation-routing.ts` / `relation-buses.ts`：共同端口、兼容候选、安全主干、标签占位、手工端口映射；只读推导。
- `relation-crossings.ts` / `relation-paint.ts`：实际 SVG 直线段交叉、共享路径一致断口、独立箭头尾段；只读推导。
- `relation-editing.ts`：边段移动、障碍验证、最小 metadata 写操作；纯函数。
- `NotebookRelations.tsx` / `useRelationRouteEditor.tsx`：明确激活、临时草稿、保存与取消、成员点选；保持画布平移与框选。
- `scene.ts` 的 SVG overview 使用同一 paint plan；原生 Excalidraw 导出保留连续语义箭头，不宣称像素外观与 HTML/SVG 层一致。

## 验收范围与限制

线跳覆盖实际 SVG 中的水平/垂直直线段，保留圆角，暂不对任意 Bézier 曲线交叉生成桥拱；离端口、转角、标签过近的交叉会给诊断并避免制造歧义。汇合只接受安全候选，不把任意相邻关系强行合并。手工编辑为正交边段，不包括自由曲线或拖动标签。实际浏览器验收结果将在部署后补充，独立于纯函数回归。
