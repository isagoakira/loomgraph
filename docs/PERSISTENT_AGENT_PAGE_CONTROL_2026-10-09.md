# 常驻 Agent 与页面控制增量

日期：2026-10-09。构建：`persistent-agent-20261009-r31.2`。

## 产品逻辑

画布始终保留可拖动的 Agent 收起入口。打开后是可移动、可调整尺寸的对话窗口；收起保留草稿、消息和当前请求。常驻的是入口和会话，模型只在发送问题后按需运行。

页面助手不要求选中对象，每轮读取实际当前图、图目录、当前可读对象与关系，以及只读选区。它跟随浏览位置，可用于连续讲解、跳转和指示。选区助手仍保留打开时的写入范围；切图后不会改成新图的编辑权限，可以回到原图继续预览和应用。不同项目、不同选区的草稿分别保留。

两个入口共用同一窗口，不另开页面。页面助手可以显式切换到当前选区；选区助手可以切回页面助手。切换不是隐藏的范围扩张。页面助手的“提出修改”不可用，编辑需先明确选中内容。

## 页面控制契约

| 控制 | 作用 |
|---|---|
| `navigate` | 打开指定图，保留返回路径和原图相机 |
| `back` | 返回上一张图并恢复视野 |
| `focus` | 定位具体对象，必要时展开其所在组的祖先 |
| `highlight` | 短暂高亮具体内容 |
| `fit` | 将当前可见图适配到视野 |
| `zoom` | 围绕画布中心调整缩放，范围 10%–300% |

模型响应将 `pageActions` 与写入候选 `operations` 分开。服务校验整个控制批次的类型、实际图和稳定目标身份；每批最多 6 项。页面控制不修改图内容、排版位置、业务状态或项目版本。内容修改继续通过已有候选校验、预览、应用和撤销路径。

控制仅由本浏览器当前提交产生的完整成功响应触发。浏览器只认领一次，等待目标画布就绪，执行后回传 `executed`、`skipped` 或 `failed` 及可读结果。服务器保存的是浏览器报告的页面控制结果，不是业务执行证明。重复 SSE、打开历史、刷新和服务恢复不重放导航。等待期间用户自行切图后，迟到控制停止；中途失败说明实际完成的项数。

每次图访问具有独立的工作区、图、访问编号和 SDK 实例身份。旧图的场景、选择、相机、就绪或图片解码回调不能作用于新访问，离开后返回同一图也如此。图内操作不重建实例；已捕获的真实编辑仍绑定原图和工作副本提交，页面切换不把旧场景重新解释成新图的编辑。

页面上下文有预算和明确遗漏：图目录最多 48 项，当前图对象、关系与文本均按预算投影，选中对象优先。模型收到文字和稳定身份，未收到页面截图。无法定位未提供的内容时应说明缺失；不猜图名或对象身份。

当前图的对象、关系和自由文本均提供可直接引用的目标对象；关系附带两端的可读标题。提示同时列出完整动作形状，要求复制提供的目标。Codex 的输出仅将最外层动作编码一次，嵌套目标保留为对象数组。另一张图只提供目录而未提供对象时，先跳图再根据新一轮上下文定位。

## 实施与验收

后端负责目录投影、控制校验、provider 响应解析和持久化回执；浏览器负责当前页面授权、一次认领、相机和临时指示。共享控制校验函数适用于服务和浏览器，避免能力列表漂移。CLI/API 仍只返回结构化结果，不获得任意浏览器脚本执行权限。

验收顺序：契约与回归测试 → 类型检查和构建 → 独立本地项目实际 CLI 导航 → 浏览器收起/展开、草稿、连续跨图问答、回执及内容版本核对。实际结果另记；测试中的假 provider 不等于真实模型验收。

本轮延续本地按需运行；不包含远端仓库发布、宿主完整聊天历史、任意新建图、业务执行或 Windows/API 实机验收。
