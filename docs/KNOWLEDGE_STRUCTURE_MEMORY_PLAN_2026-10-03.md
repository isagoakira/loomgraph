# 知识结构与阅读记忆修正

## 本轮校正

用户指出：文章推进已有改善，但缺少知识图谱/思维导图式延伸、适度原子化和结构化卡片；部分概念未铺垫，跨段再次出现时距离过远，局部概念引进不完整。上一轮的数字与按钮检查没有覆盖这些缺口，不能据此判定表达需求整体通过。

本轮将同一份事实组织为“讲解路线 + 可延伸的知识结构 + 每处自足的阅读上下文”。保留原样例与全部历史内容，用新样例验证，不替换正式构建。

## 表达与交互

- 卡片承载一个能独立理解的知识中心：名称、当前含义、用途，补充细节原位展开。过小的词语片段归入卡片正文，不单独造节点。
- 图中明确标示包含、分工、依据、产生、对照、评价、修订等关系；讲解顺序与知识关系分别记录。每条关系能读成一句完整的话。
- 总体图展示问题、方法、使用、更新和检验之间的关系；每一步就地提供较小的概念邻域。节点可沿关系看相邻解释，也可定位回主干，返回保存原位置。
- 再次使用旧概念前提供一行自足回顾，并说明它为什么在此处需要。必要解释直接可见；完整细节才需要展开。
- 每个局部图先以约 4–6 个知识中心、每处约 1–3 个新概念块作为编排审查目标。数字是可调整的设计启发式，需实读验证，不是对人类记忆容量的定额。
- 窄视图重新安排卡片和关系，不把整张图等比例缩成看不清的小字。鼠标悬停不激活卡片操作。

## Harness 需要维护的上下文

一次局部修改同时读取当前理解问题、必要旧概念及一行定义、前一步结论、待引入知识中心、后续承接、卡片内容、明确关系及原文来源。坐标相邻或“一跳邻居”不能替代这些语义前提。

检查不只问“之前定义过吗”，还问“当前读者能否在这处直接拿到足够的定义与作用”。概念间隔、介入的新概念量和长研究分支作为回顾提示的信号；真实阅读判断优先于机械阈值。

概念原子、关系、步骤与来源采用稳定身份；同一概念可有多处表示。局部改写不创建互相矛盾的定义副本。批注继续绑定原对象/分节/段落及观察版本。

## 验收

1. 不依赖弹窗、前翻或记住很早的段落，也能解释当前步骤必要的 F/R、概率与信心、校准、子类别、预测/复盘轨迹。
2. 默认能看见卡片结构及带语义的连线，而不仅是文章目录或八张顺序卡。
3. 从节点可查邻接关系和对应解释；原位展开与返回不丢当前阅读位置。
4. 原文 104 个结果值与配置边界保持；概念解释、教学例子与作者实验分开标记。
5. 在桌面与窄视图检查文字、箭头端点、关系标签、节点重叠及键盘操作。模型审阅、确定性检查和浏览器操作分别记录；真人理解仍单独验收。

## 本轮实施结果

已生成 29 个知识中心、55 条规范关系、7 条独立教学边和九个实际卡片结构视图。三个局部图保留七节点，并把 newConceptGroups 与必要回顾明确显示为同一局部阅读上下文；未声称严格通过 4–6 节点窗口。

浏览器 24/24，已安装 MCP 的八步局部阅读上下文 24KB 预算往返 8/8。项目由 R102 增量到 R105，原对象与批注逐项未改。生成指引源码已更新，正式阅读器及通用排布未升级；真人理解仍待实读。变更、证据和边界汇总到[验收记录](KNOWLEDGE_STRUCTURE_MEMORY_ACCEPTANCE_2026-10-03.md)。
