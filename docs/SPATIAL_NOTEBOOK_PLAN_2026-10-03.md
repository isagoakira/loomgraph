# 统一图文笔记实施与验收计划

用户已明确：文档阅读与自由排版不能分立。目标是同一张可编辑的笔记平面，让完整文字、概念图解和知识关系相互穿插，兼顾自由摆放与自动排版。

## 表现规则

- 同一平面阅读、编辑、选择和批注；不通过文章视图与画布视图切换来拼接体验。
- 默认完整显示当前层必要说明，不截断标题，不在文字块中设置滚动窗口。
- 以中心、命名分支、概念之间的动词和邻近说明组织二维空间；图解直接占据自然尺寸。
- 普通说明使用轻量排版，密集概念条目和展开的研究细则使用适当边界；操作控件只在选中或键盘聚焦时出现。
- 平移和缩放作用于整张笔记，经过文字或节点不截停；文字仍可原位编辑和选文批注。

## 实施边界

在原生 Agent Visual Canvas 的内容层与排版流程中增加 notebook 图配置。Graph.metadata.notebook 声明中心与分支；Representation.style.notebook 声明节点作用、分支与显示规则；自由元素的 customData.notebook 声明正文、标题和图解归属。保留现有目标身份和事务协议。

新增 ForecastCompass 统一笔记图，复用已经核验的知识实体、结果数组与 SVG 资源。R118 以前的原图、用户文本框“我觉得不对”、批注及资源保持原样。新图是可增量维护的原生项目内容。

自动整理按结构分支安排文字与图解，使用实际文字尺寸或保守估算提供空间；用户固定的位置不参与移动。候选与应用使用同一基线修订。阅读、展开和缩放本身不形成内容修订。

## 验收

1. 真实本地工作台展示统一笔记，没有 notebook 图的阅读/自由排版双视图切换。
2. 文字与图解在同一二维空间穿插；整图结构与局部分支都能取景，主关系可以连续追踪。
3. 必要正文完整显示、无卡内滚动、无文字裁切；展开、编辑、选中批注仍可用。
4. 自动整理避免内容碰撞，保留固定对象；重复整理保持稳定，不产生空修订。
5. 拖动与平移通过节点不截停，刷新不误写；原项目对象和用户新增文本逐项保留。
6. 类型检查、相关单元测试、生产构建及实际浏览器检查通过，记录当前安装与运行边界。

## 本轮增量：组织、编辑和删除

同一张笔记采用小团簇组织。每个块声明问题、分工、主组织语法、必要成员和输入输出入口。全局总览只展示各块分工；块内默认突出必要内容，正文和研究细则仍在同一平面就地展开。远距语义使用关联入口，不在当前块中拉跨屏长线。思维分支、流程箭头、反馈与引用分别声明，每条关系绑定稳定表示身份。

理解优先呈现讲解结构；监控优先追加当前范围的真实进行中、阻塞、失败和待确认任务，同时给出状态、来源与观察时间。监控不会自动切图、移动视口或把论文方法标成真实运行。组织 harness 将当前块、接口和有界跨块链接加入 Agent 上下文，并显式记录省略。

文本框原位编辑默认在停顿后自动保存，中文输入组合阶段暂停；保存时保留并发几何与未知扩展，文字冲突保留草稿。位置、宽高和旋转可直接调整。手动移动只保存位置，阅读展开高度仅用于临时避让。人工固定位置在自动整理中保持不变。

删除控件位于选中内容附近、顶部和选中面板，可对多处选中目标批量操作；聚焦画布块时 Delete/Backspace 使用相同事务。删除只移除本图表示、自由内容及明确绑定本图的失效关系，同时清理阅读顺序、分支、团簇和入口引用。共享实体、其他图和批注保留。撤销通过新的版本恢复。

验收必须覆盖：实际窄视口、展开避让与收起、临时视图零误写、原位编辑保存、自由变形、模块删除与撤销、刷新保持，以及旧对象逐项保留。实际结果记录在本轮 evidence 中；源码通过检查不等于运行页完成部署。
